# Le Lis et le Lion — Forçage coiffure/barbe pour personnages scriptés
#
# Pourquoi ce fichier existe :
# Meme quand un personnage historique a des genes hairstyles=/beards= bien
# definis dans sa DNA (common/dna_data), le moteur peut choisir un autre
# gabarit au rendu si aucun poids n'est explicitement force pour CE
# personnage precis. La methode officielle (wiki de modding CK3, section
# "Hairstyles and beards for scripted characters") consiste a ajouter un
# modifier = { add = 200 exists = character:<id> this = character:<id> }
# sous l'entree du gabarit voulu, normalement DANS les fichiers vanilla
# gfx/portraits/portrait_modifiers/99_hairstyles_scripted_characters.txt
# et 99_beards_scripted_characters.txt.
#
# On evite volontairement de recreer un fichier au meme chemin que ces
# fichiers vanilla : un fichier de mod avec le meme chemin relatif
# remplace entierement le fichier vanilla correspondant, ce qui effacerait
# les forcages que Paradox a deja mis en place pour ses propres
# personnages scriptes (Charlemagne, etc.). A la place, ce fichier cree
# ses propres groupes de modificateurs (noms uniques, prefixes lis_lion_),
# qui n'entrent jamais en collision avec du contenu vanilla ou un autre
# mod, et qui ne s'appliquent qu'aux 4 personnages vises via exists/this.
#
# ATTENTION (corrige par rapport a la version precedente) :
# - Karl/Charles IV = personnage custom 462614 (nom "Wenzel"/"Karl" dans
#   house_luxemburg), PAS 69466 : verifie dans 00_lis_lion_portraits_dna.txt.
# - Barbe de Karl = fp2_beards_straight (celle presente dans sa DNA reelle),
#   pas no_beard.
# - Un groupe de premier niveau et son template enfant ne doivent pas porter
#   le meme nom : corrige ci-dessous.
#
# Si un template n'est pas reconnu par le jeu, error.log indiquera le nom
# exact — plus qu'a corriger.
